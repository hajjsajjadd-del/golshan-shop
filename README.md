# فروشگاه تخصصی لوازم برق خودرو گلشن

نسخه اجرایی اولیه با Django؛ مناسب توسعه مرحله‌ای به فروشگاه تجاری.

## امکانات پیاده‌سازی‌شده
- صفحه اصلی راست‌چین با رنگ‌های سفید، سرمه‌ای و آبی روشن
- دسته‌بندی تخصصی برق و الکترونیک خودرو
- جست‌وجو در نام، کد فنی، برند و توضیحات محصول
- فیلتر دسته‌بندی و مرتب‌سازی
- صفحه جزئیات محصول و نمایش مشخصات فنی
- سبد خرید مبتنی بر نشست کاربر
- ثبت سفارش آزمایشی و کاهش موجودی پس از ثبت
- فرم تماس
- پنل مدیریت Django برای محصولات، برندها، دسته‌ها، خودروها، سفارش‌ها و پیام‌ها
- افزودن تصاویر محصول و مشخص کردن سازگاری با خودرو

## اجرای محلی
Python 3.11 یا جدیدتر پیشنهاد می‌شود.

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
python manage.py makemigrations shop
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

فروشگاه: http://127.0.0.1:8000/
مدیریت: http://127.0.0.1:8000/admin/

## ورود اطلاعات اولیه
از پنل مدیریت دسته‌ها، برندها و محصولات را ثبت کنید. اطلاعات نمونه واقعی نیستند و هیچ قیمت یا سازگاری ساختگی در پروژه درج نشده است.

## پیش از انتشار واقعی
- `DJANGO_SECRET_KEY` را با مقدار تصادفی و محرمانه تنظیم کنید.
- `DJANGO_DEBUG=0` و `DJANGO_ALLOWED_HOSTS` را تنظیم کنید.
- PostgreSQL و پشتیبان‌گیری خودکار را برای محیط عملیاتی فعال کنید.
- درگاه پرداخت معتبر را با مستندات شرکت پرداخت متصل کنید؛ در این نسخه پرداخت واقعی فعال نیست.
- سرویس پیامک، ارسال ایمیل، قوانین ارسال و مرجوعی را با اطلاعات واقعی فروشگاه پیکربندی کنید.
- HTTPS، محدودیت نرخ ورود، مانیتورینگ و تست امنیتی مستقل انجام دهید.

این پروژه نقطه شروع اجرایی است، نه ادعای آماده‌بودن برای دریافت پول واقعی از مشتری.
